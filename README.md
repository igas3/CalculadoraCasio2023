# CalculadoraCasio2023
Criação de uma calculadora basica em JS CSS e HTML
Projeto desenvolvido em 2023 com foco na implementação de uma calculadora básica em HTML, CSS e JavaScript, reproduzindo o comportamento essencial de uma calculadora tradicional. O objetivo do projeto foi a prática de lógica de interface, manipulação do DOM e estilização de componentes visuais.

Visão geral

A aplicação permite a realização das principais operações matemáticas básicas e inclui um recurso de personalização visual através da mudança de cores do layout ao clicar no seletor circular posicionado ao lado do logotipo “CASIO”.

Funcionalidades

Operações básicas de calculadora (adição, subtração, multiplicação e divisão)

Exibição do resultado no visor

Limpeza de valores e reinício das operações

Alteração de tema/colorização da interface por meio do seletor lateral

Interface inspirada no design de calculadoras físicas

Fluxo de uso

O usuário interage com os botões numéricos e operadores.

Os valores são exibidos no visor da calculadora.

Ao confirmar a operação, o resultado é calculado e exibido.

A mudança de cor do tema pode ser ativada clicando na bolinha ao lado do logotipo.
